Want a real voice instead of the computer voice? Record your own.
Make a folder named after the verse (for example `2-47`) and add any of these files:
hook.mp3, shloka.mp3, meaning.mp3, example.mp3, lesson.mp3, quiz.mp3, answer.mp3, outro.mp3
Any file you add replaces the computer voice for that part of the video. Missing parts use the computer voice.
